## Session: security review and headers
**Done**
- Reviewed the server and probed the live site (Cloudflare and straight to :8470): no way found to read the OpenRouter key
  (not in the bundle, git history, logs or any API reply; path tricks refused by Cloudflare and by the app; foreign
  socket origins refused). Owner moved the server to its own OpenRouter key with spend limits.
- Security headers on every response (`headers.ts` + test): CSP, X-Frame-Options, nosniff, Permissions-Policy, COOP/CORP,
  HSTS over HTTPS. Checked live: host, play and admin pages work, and both audition pages play and keep picks.

**Learned**
- A sandboxed `/media` page broke its own audio (CORP vs. opaque origin) and localStorage, so `/media` gets a no-network
  CSP instead (in gotchas).
