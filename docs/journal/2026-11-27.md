## Session: Game #2 drama (sound, light, pauses)

- Engine needs: reveal lines split into setup + payoff clips with the pause set by the platform; reveals as timed cue
  lists in the host view so a reconnecting TV resumes mid-sequence.
- Follow-up (owner: "animations in line with the sound design"): the demo now runs sound and picture off one timeline,
  every sound paired with a visual (heartbeat throbs the light, quill writes the name per stroke, silence freezes the
  flames, bell sends a ring and shake, hiss draws the serpent, each puff snuffs one candle with smoke, seal pulses while
  Salty talks). Pairing table added to the design doc.
- Names: players type their own on join (ADR 0016). Pre-recorded reveal lines never say a name ("The one we cast
  out... was..."); the TV shows it. Saying names would need live TTS (ADR 0013 open question).
